# iRap Mobile — Android + iOS

Aplicativo oficial do iRap — Chamado do Rap, desenvolvido com Expo/React Native para uma única base Android e iOS.

## Rodar localmente

```bash
cd mobile
npm install
npx expo start
```

## Builds

```bash
npm run build:android
npm run build:ios
npm run build:all
```

Os builds de produção são feitos pelo EAS Build. Para publicar, é necessário vincular as contas de desenvolvedor da Google Play e Apple Developer ao EAS.

## Identificadores

- Android: com.leandrozzm3.irap
- iOS: com.leandrozzm3.irap

## Recursos

- Batalhas 1x1
- 3, 4 ou 5 rounds
- Flow, Rima e Impacto
- Placar acumulado
- Histórico local
- Interface dark responsiva
