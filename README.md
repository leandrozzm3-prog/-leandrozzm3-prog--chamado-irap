# iRap — Chamado do Rap

Arena web responsiva para organizar batalhas de rap, controlar rounds, pontuar critérios e manter histórico local.

## Recursos
- Dois MCs e seleção de 3, 4 ou 5 rounds.
- Pontuação por Flow, Rima e Impacto.
- Controle de turno e round.
- Histórico persistido no navegador.
- Interface responsiva para celular e desktop.
- Zero dependências externas.

## Uso
Abra `index.html` no navegador. O projeto está preparado para publicação via GitHub Pages.

## Estrutura
- `index.html` — interface.
- `styles.css` — identidade visual.
- `app.js` — lógica da arena.

## Próximas evoluções
Backend, contas, ranking online, salas em tempo real, perfis de MCs, votação pública e armazenamento em nuvem.
